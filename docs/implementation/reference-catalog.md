Status: PRE-IMPLEMENTATION REFERENCE MAP

Drive remains the source of truth for the actual files; do not duplicate the boards into the repository unless there is a later explicit asset-export decision.

## Interpretation rule

A reference board may contain both accepted and rejected elements. Never implement an entire board by screenshot transcription. Build from written design authority and reusable semantic components, using the boards to answer visual questions such as composition, density, imagery treatment and hierarchy.

When a board and written authority disagree, written authority wins.
